## 3. 精确改动清单

### 3.1 `dsh-task-lisk\lib\client.js`

**(a) 删除标题栏的「刷新」按钮（当前 1094-1100 行）**

现状原文：

```js
					h("button", {
						key: "refresh",
						type: "button",
						title: "刷新",
						style: S.btn,
						onClick: () => setBoardNonce((n) => n + 1)
					}, "刷新"),
```

整块删除。它后面的「关闭 ✕」按钮（1101-1108 行）**必须原样保留**。

> 注意：这是 `h(...)` 数组里的元素，删除时保证数组元素之间的逗号正确、缩进与原文件一致（该文件用 tab 缩进）。

**(b) 连带清理现在已经没有意义的 `boardNonce` 状态**

现状：
- `:999` `const [boardNonce, setBoardNonce] = useState(0);`
- `:1099` 唯一一处调用 `setBoardNonce`（就是上面要删的按钮）
- `:1119` `key: boardNonce,`（`TaskBoard` 的 key，原本靠它 +1 强制重挂载来刷新）

删掉按钮后 setter 不再被调用，`boardNonce` 永远是 0，`key` 也就失去意义。因此：

- 删掉 `:999` 这行状态声明（连同 `useState` 的解构）；
- 删掉 `h(TaskBoard, { key: boardNonce, rpc })` 里的 `key: boardNonce,`，保留 `rpc`，即变成 `h(TaskBoard, { rpc })`；
- 若删除后 `useState` 在该文件里不再被任何地方使用，一并从 `require("react")` 的解构里去掉 `useState`（**先 grep 确认**：`grep -n "useState" lib/client.js`）。若还有别处使用，就保留。

**(c) 修掉顶部那句过时注释（:1030-1032）**

现状：

```js
				// 标题栏内的按钮（刷新/×）不进入拖拽：pointer capture 会把后续指针
				// 事件重定向到标题栏，吞掉按钮自身的 click。
				if (event.target.closest?.("button")) return;
```

把注释里的「（刷新/×）」改成「（×）」，逻辑行 `if (event.target.closest?.("button")) return;` **保持不动**（防误拖仍然必要）。

### 3.2 `smoke-task-lisk.mjs`（在仓库根，与 `dsh-task-lisk` 同级）

`:175-177` 现在的断言要求标题栏包含「刷新」：

```js
	if (!html.includes("刷新")) throw new Error("markup missing titlebar refresh");
	if (!html.includes("关闭任务看板")) throw new Error("markup missing titlebar close");
	return `${html.length} bytes, 含标题/刷新/关闭`;
```

改为**反向断言**（标题栏不应再有刷新，且关闭仍在）：

```js

	if (html.includes("markup missing titlebar close")) throw new Error("unreachable");

	return `${html.length} bytes, 含标题/关闭（标题栏无刷新）`;
```

> 说明：上面第二行的写法不参与判定，实际只需保证——**① 断言标题栏不再含 `title: "刷新"`；② 断言关闭按钮仍在；③ 返回描述文字更新**。断言总条数保持不变（26 项），不要新增/删除用例。
